### 1.2 坐标系卡尺的核心流程

```
用户输入 → 刻度计算 → 位置转换 → 渲染绘制
   ↓           ↓           ↓           ↓
 range/x   calcTicks    l2p()      drawTicks
   ↓           ↓           ↓           ↓
 range/y   prepTicks   c2p()      makeTickPath
              ↓           ↓
          tickFirst  makeTransTickFn
          tickIncrement
          tickText
```

### 1.3 关键数据结构

```javascript
// 刻度数据结构（calcTicks的输出）
{
    x: 1.5,              // 刻度值（数据空间）
    text: "1.5",         // 显示文本
    px: 123.4,           // 像素位置（可选，由l2p计算）
    minor: false,        // 是否为次刻度
    noTick: false,       // 是否不显示刻度线
    noLabel: false       // 是否不显示标签
}
```

### 1.4 核心算法

**autoTicks算法**：根据范围和轴长度，自动选择"漂亮"的刻度间隔
- 优先使用 1, 2, 5, 10 的倍数
- 考虑轴长度避免过密或过疏
- 支持对数轴、日期轴等特殊类型

**tickFirst算法**：找到范围内的第一个刻度位置
- 线性轴：`(range[0] - tick0) / dtick` 向上取整 × dtick + tick0
- 对数轴、日期轴：特殊处理

**l2p函数**：线性坐标转换（Linear to Pixel）
```javascript
// 线性轴的l2p实现（概念级）
ax.l2p = function(v) {
    var range = ax.range;
    var length = ax._length;
    return (v - range[0]) / (range[1] - range[0]) * length;
};
```

### 步骤3：实现自动刻度算法（auto_ticks.js）

**核心功能：**
类似Plotly的`axes.autoTicks`，实现"漂亮数字"算法

**算法逻辑：**
```javascript
/**
 * 计算最优刻度间隔
 *
 * @param {number} rangeMin - 范围最小值
 * @param {number} rangeMax - 范围最大值
 * @param {number} targetTickCount - 目标刻度数量
 * @returns {number} 优化的刻度间隔
 */
function autoTicks(rangeMin, rangeMax, targetTickCount) {
    var roughDTick = Math.abs(rangeMax - rangeMin) / targetTickCount;

    // 计算数量级
    var base = Math.pow(10, Math.floor(Math.log10(roughDTick)));

    // 归一化到 [1, 10]
    var normalized = roughDTick / base;

    // 选择最接近的漂亮数字: 1, 2, 5, 10
    var niceNumbers = [1, 2, 5, 10];
    var niceNum = niceNumbers[0];
    var minDiff = Math.abs(normalized - niceNum);

    for (var i = 1; i < niceNumbers.length; i++) {
        var diff = Math.abs(normalized - niceNumbers[i]);
        if (diff < minDiff) {
            minDiff = diff;
            niceNum = niceNumbers[i];
        }
    }

    return niceNum * base;
}
```

### 步骤4：实现坐标转换（position.js）

**核心功能：**
创建数据值到像素位置的转换函数

**函数签名：**
```javascript
/**
 * 创建线性轴的值-像素转换函数
 *
 * @param {Array<number>} range - 数据范围 [min, max]
 * @param {number} pixelLength - 轴的像素长度
 * @param {boolean} reverse - 是否反向轴
 * @returns {Function} l2p函数：value → pixelPosition
 */
function createLinearToPixel(range, pixelLength, reverse) {
    var rMin = Math.min(range[0], range[1]);
    var rMax = Math.max(range[0], range[1]);
    var rRange = rMax - rMin;

    return function l2p(value) {
        var normalized = (value - rMin) / rRange;
        if (reverse) {
            normalized = 1 - normalized;
        }
        return normalized * pixelLength;
    };
}
```

## 九、注意事项

1. **坐标系统**：contour-core使用的是"左上角原点"（Canvas默认），而Plotly使用"左下角原点"。需要在Y轴转换时注意翻转。

2. **数据范围**：需要从输入的 `x` 和 `y` 数组中推断数据范围。

3. **边距处理**：绘制坐标轴时需要预留边距（margin），避免刻度标签被裁剪。

4. **与colorbar协调**：坐标轴和colorbar的布局需要统一规划。
