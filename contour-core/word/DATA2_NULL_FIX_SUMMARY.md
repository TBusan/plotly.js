# Data2 空值渲染问题修复总结

## 问题描述

当设置 `connectgaps=true` 时，用户期望 data2（包含空值）渲染的等值线应该与 data1（无空值）相似，因为空值会被插值填充。但实际上两者渲染效果差异很大。

## 根本原因

**原始 data2 有 51.8% 的数据是 null**，分布如下：
```javascript
var data2 = [[null, null, null, 12, 13, 14, 15, 16],  // 前3个都是null
    [null, 1, null, 11, null, null, null, 17],        // 5个null
    [null, 2, 6, 7, null, null, null, 18],           // 4个null
    ...
```

插值后的值与 data1 的原始值存在显著差异：

| 位置 | data1 | data2 (插值后) | 差异 |
|------|-------|---------------|------|
| [0][0] | 2 | 2.98 | +49% |
| [0][1] | 4 | 3.79 | -5% |
| [0][2] | 7 | 7.38 | +5% |
| [6][0] | 11 | 11.37 | +3% |
| [6][1] | 14 | 13.66 | -2% |

**这不是 bug**，而是插值算法的本质限制：
- 当 null 比例过高时，插值无法准确还原原始数据
- 插值是一种"猜测"，基于有限的有效值估计空值区域的值
- 等值线是基于插值后的数据计算的，自然与原始数据的等值线不同

## 解决方案

### 方案：修改 data2 使有效值与 data1 对应位置一致

使用注释中原本设计的 data2 版本：
```javascript
var data2 = [[2, 4, 7, 12, 13, 14, 15, 16],  // 第一行与data1完全相同
    [null, 1, 6, 11, 12, 13, 16, null],
    [null, null, 7, 7, 11, 14, 17, null],
    [null, null, 8, 8, 13, 15, 18, null],
    [null, null, null, 9, 16, 18, 20, 19],
    [9, 10, 5, 27, 23, 21, 21, 21],
    [11, 14, 17, 26, 25, 24, 23, 22]];
```

### 验证结果

- Null 比例：19.6%（从 51.8% 降低）
- edgeVal2：2（与 data1 相同）
- 路径匹配度：**100%**（所有 15 个层级的路径结构完全一致）

## 关键要点

### 1. connectgaps 的作用

```
connectgaps=true  → 插值 + 不遮罩 → 等值线穿过空值区域
connectgaps=false → 插值 + 遮罩   → 空值区域被白色方块覆盖
```

**重要**：无论 connectgaps 设置如何，计算时都会进行插值。connectgaps 只控制渲染时的遮罩行为。

### 2. 插值的影响因素

| 因素 | 影响 |
|------|------|
| null 比例 | 越高，插值越不准确 |
| null 分布 | 连续大片的 null 比分散的 null 更难插值 |
| 有效值一致性 | 有效值与目标值越接近，插值效果越好 |

### 3. 何时插值效果较好

- Null 比例 < 20%
- Null 值分散（不形成大片区域）
- 周围有足够的有效值作为参考
