# 等值线空值处理优化

## 问题分析

### 当前问题
在 `data-samples.html` 中，data2 包含大量 null 值的数据无法正确渲染等值线（图5），而 plotly.js 原版可以正确渲染（图6）。

### 根本原因
**contour-core 与 plotly.js 处理 null 值的方式完全不同：**

#### Plotly.js 的方式：插值填充
1. **数据清理阶段**（`src/traces/heatmap/clean_2d_array.js`）:
   - 将非数值（null、undefined、NaN 等）转换为 `undefined`

2. **查找空值**（`src/traces/heatmap/find_empties.js`）:
   ```javascript
   // 找出所有 undefined 的位置
   // 统计每个空值周围的有效邻居数量
   // 按邻居数量降序排序（优先处理邻居多的）
   ```

3. **二维插值**（`src/traces/heatmap/interp2d.js`）:
   ```javascript
   // 使用拉普拉斯方程迭代求解
   // 每个空值 = 周围邻居的平均值
   z[i][j] = neighborSum / neighborCount;
   ```

4. **Marching Squares 不检查 null**（`src/traces/contour/make_crossings.js`）:
   - 直接对所有网格单元进行 marching squares
   - **没有** null 检查逻辑
   - 插值后的数据已经没有空值

#### Contour-core 的方式：跳过空值单元
1. **生成 null 掩码**（`null_handling/mask.js`）:
   ```javascript
   var isNull = val === null || val === undefined || isNaN(val);
   maskRow.push(isNull);
   ```

2. **Marching Squares 跳过含 null 的单元**（`marchingsquares.js`）:
   ```javascript
   // 检查单元四个角是否有 null
   if (nullMask[yi][xi] || nullMask[yi][xi + 1] ||
       nullMask[yi + 1][xi] || nullMask[yi + 1][xi + 1]) {
       hasNull = true;
   }
   // 跳过这个单元
   if (hasNull) continue;
   ```

### 问题所在
**跳过含 null 的单元会破坏等值线的连续性**：

```
示例数据：
[null, null, 10, 20]
[null, 30,   40, 50]
[60,   70,   80, 90]

Plotly.js（插值后）：
[45,   42,   10, 20]
[52,   30,   40, 50]
[60,   70,   80, 90]
→ Marching squares 正常工作，等值线连续

Contour-core（跳过单元）：
跳过 (0,0), (0,1), (1,0) 单元
→ 等值线断裂或无法生成
```

## 解决方案

### 方案 1：实现二维插值（推荐）
**优点**：
- 与 plotly.js 完全一致
- 生成平滑的等值线
- 适合科学可视化

**缺点**：
- 需要额外代码
- 计算开销略大

**实现步骤**：
1. 移除 `marchingsquares.js` 中的 null 检查
2. 实现 `findEmpties()` 函数
3. 实现 `interp2d()` 函数
4. 在 `computeContours()` 中调用插值

### 方案 2：边界标记法
**优点**：
- 代码简单
- 计算快速

**缺点**：
- 与 plotly.js 行为不一致
- 等值线会在 null 边界处中断

**实现步骤**：
1. 在 marching squares 中，将 null 值视为特殊值（如 -Infinity）
2. 在边界处生成等值线
3. 渲染时屏蔽 null 区域

### 实现细节

#### 1. findEmpties() 核心逻辑
```javascript
function findEmpties(z) {
    var empties = [];
    for (var i = 0; i < z.length; i++) {
        for (var j = 0; j < z[i].length; j++) {
            if (z[i][j] === undefined) {
                var neighborCount = countNeighbors(z, i, j);
                empties.push([i, j, neighborCount]);
            }
        }
    }
    // 按邻居数量降序排序
    return empties.sort((a, b) => b[2] - a[2]);
}
```

#### 2. interp2d() 核心逻辑
```javascript
function interp2d(z, emptyPoints) {
    // 第一遍：填充初始值
    for (var p = 0; p < emptyPoints.length; p++) {
        var i = emptyPoints[p][0];
        var j = emptyPoints[p][1];
        z[i][j] = averageNeighbors(z, i, j);
    }

    // 迭代优化（最多 100 次）
    for (var iter = 0; iter < 100; iter++) {
        var maxChange = 0;
        for (var p = 0; p < emptyPoints.length; p++) {
            var i = emptyPoints[p][0];
            var j = emptyPoints[p][1];
            var oldVal = z[i][j];
            var newVal = averageNeighbors(z, i, j);
            z[i][j] = newVal;
            maxChange = Math.max(maxChange, Math.abs(newVal - oldVal));
        }
        if (maxChange < 0.01) break; // 收敛
    }

    return z;
}
```

### 预期结果
- **修复前**：空白（无等值线）
- **修复后**：与 plotly.js 一致的渲染效果

### 性能影响
- 插值时间：O(空值数量 × 迭代次数)
- 对于稀疏空值：几乎无影响
- 对于密集空值：可能增加 10-30% 计算时间

## 兼容性

### 选项控制
```javascript
var options = {
    connectgaps: true,  // 是否插值空值（默认 true）
    // ... 其他选项
};
```

### 向后兼容
- 默认启用插值（与 plotly.js 一致）
- 设置 `connectgaps: false` 可禁用（跳过空值单元）

## 总结

**关键要点**：
1. Plotly.js 使用**插值填充**而非跳过空值单元
2. 跳过单元会破坏等值线连续性
3. 实现二维插值可完全解决此问题

**实施优先级**：
1. ✅ 高优先级：实现 findEmpties 和 interp2d
2. ✅ 高优先级：移除 marchingsquares 中的 null 检查
3. ⚠️ 中优先级：添加 connectgaps 选项
4. ⚠️ 低优先级：性能优化（缓存、加速）
