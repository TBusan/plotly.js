## 背景与目标

### 背景

Plotly.js 原生提供丰富的等值线交互功能（详见 `contour交互机制详解.md`），包括：

| 功能 | 描述 |
|------|------|
| 缩放 | 滚轮缩放、框选缩放、轴向缩放 |
| 平移 | 拖拽移动视图 |
| 悬停 | 显示数据点信息 |
| 双击重置 | 恢复初始视图 |
| 坐标轴联动 | 多轴同步更新 |

当前 `contour-core` 已实现**纯计算层**，但**完全缺乏交互能力**，只能进行静态渲染。

### 目标

为 `contour-core` 添加**独立的交互层**，使其具备：

1. 与 Plotly 相当的交互体验
2. 不依赖 Plotly 的独立运行能力
3. 支持多种渲染器（Canvas、SVG）
4. 可扩展的插件化架构

## 功能需求定义

### 1. 核心交互功能

#### 1.1 缩放（Zoom）

```javascript
// 需求描述
- 滚轮缩放：以鼠标位置为中心的定点缩放
- 框选缩放：拖拽矩形区域进行缩放
- 轴向缩放：拖拽坐标轴端点进行单向缩放
- 缩放约束：支持比例锁定（等比缩放）

// 事件类型
- wheel: 滚轮事件
- mousedown + drag: 框选/轴缩放
```

#### 1.2 平移（Pan）

```javascript
// 需求描述
- 主区域平移：拖拽绘图区域移动视图
- 轴向平移：沿坐标轴方向平移
- 边界约束：限制平移范围在数据边界内

// 事件类型
- mousedown: 开始平移
- mousemove: 计算平移距离
- mouseup: 完成平移
```

#### 1.3 悬停提示（Hover）

```javascript
// 需求描述

- 坐标显示：实时显示当前坐标
- 自定义格式：支持用户自定义提示内容

// 事件类型
- mousemove: 实时更新提示位置和内容
- mouseenter: 显示提示框
- mouseleave: 隐藏提示框
```

#### 1.4 双击重置（Reset）

```javascript
// 需求描述
- 恢复初始视图范围
- 可选动画过渡效果

// 事件类型
- dblclick: 触发重置
```

### 2. 高级交互功能

#### 2.1 多设备支持


### 模块职责

#### 1. EventManager（事件管理器）

```javascript
/**
 * 职责：
 * 1. 统一管理所有 DOM 事件监听
 * 2. 事件委托和冒泡控制
 * 3. 事件与处理器的映射
 * 4. 第三方库集成点
 */

class EventManager {
    // 绑定事件
    on(element, event, handler, options)

    // 解绑事件
    off(element, event, handler)

    // 暂停/恢复事件
    pause()
    resume()

    // 销毁所有监听
    destroy()
}
```

#### 2. StateManager（状态管理器）

```javascript
/**
 * 职责：
 * 1. 维护视图状态（范围、缩放级别）
 * 2. 状态变化历史（用于撤销/重做）
 * 3. 状态约束（边界检查）
 * 4. 状态变化事件发布
 */

class StateManager {
    // 当前状态
    state: {
        view: {
            xMin, xMax, yMin, yMax,
            scaleX, scaleY,
            centerX, centerY
        },
        transform: {
            translateX, translateY,
            scale
        },
        interaction: {
            isDragging,
            isZooming,
            dragStart,
            zoomCenter
        }
    }

    // 更新状态（带约束检查）
    update(newState)

    // 获取当前视图范围
    getViewRange()

    // 重置到初始状态
    reset()

    // 状态变化回调
    onChange(callback)
}
```

#### 3. CoordinateConverter（坐标转换器）

```javascript
/**
 * 职责：
 * 1. 数据坐标 ↔ 屏幕坐标双向转换
 * 2. 考虑当前缩放和平移状态
 * 3. 支持不同坐标轴类型（线性、对数）
 */

class CoordinateConverter {
    // 数据坐标 → 屏幕坐标
    dataToPixel(x, y)

    // 屏幕坐标 → 数据坐标
    pixelToData(px, py)

    // 更新转换参数（状态变化时调用）
    update(viewState)

    // 设置坐标轴范围
    setAxes(xRange, yRange)
}
```

#### 4. 交互处理器（Interaction Handlers）

```javascript
/**
 * ZoomHandler - 缩放处理器
 */
class ZoomHandler {
    // 滚轮缩放
    handleWheel(event, state, converter)

    // 框选缩放
    handleBoxSelect(start, end, state, converter)

    // 轴向缩放
    handleAxisZoom(axis, delta, state, converter)
}

/**
 * PanHandler - 平移处理器
 */
class PanHandler {
    // 开始拖拽
    startDrag(event)

    // 拖拽中
    handleDrag(event, state, converter)

    // 结束拖拽
    endDrag(event)
}

/**
 * HoverHandler - 悬停处理器
 */
class HoverHandler {
    // 处理鼠标移动
    handleMove(event, converter, data)

    // 获取最近的数据点
    findNearestPoint(px, py, data)

    // 格式化提示内容
    formatTooltip(point, config)
}
```

## 第三方库选型

### 推荐方案 1：D3.js（强烈推荐）

**优势：**
- 成熟的坐标系统和缩放行为（d3-zoom）
- 优秀的过渡动画（d3-transition）
- 灵活的事件处理
- 与 Plotly.js 有相似的架构思想

**核心模块：**
```javascript
import { zoom, zoomIdentity } from 'd3-zoom';
import { select } from 'd3-selection';
import { easeCubicOut } from 'd3-ease';
```

**使用示例：**
```javascript
// 创建缩放行为
const zoomBehavior = zoom()
    .scaleExtent([0.5, 10])      // 缩放范围
    .on('zoom', (event) => {
        const { transform } = event;
        state.update({
            transform: { k: transform.k, x: transform.x, y: transform.y }
        });
        requestRender();
    });

// 应用到 SVG/Canvas
select(svgElement)
    .call(zoomBehavior);

// 程序化缩放
select(svgElement)
    .transition()
    .duration(750)
    .call(zoomBehavior.transform, zoomIdentity.translate(x, y).scale(k));
```

**推荐指数：⭐⭐⭐⭐⭐**

### 推荐方案 2：Hammer.js（移动端友好）

**优势：**
- 统一触摸和鼠标事件
- 内置手势识别（pinch、pan、tap、swipe）
- 轻量级（~7KB gzipped）

**使用示例：**
```javascript
import Hammer from 'hammerjs';

const mc = new Hammer(canvasElement);

// 启用识别器
mc.get('pinch').set({ enable: true });
mc.get('pan').set({ direction: Hammer.DIRECTION_ALL });

// 事件绑定
mc.on('panstart', (e) => handler.startDrag(e));
mc.on('panmove', (e) => handler.handleDrag(e));
mc.on('panend', (e) => handler.endDrag(e));

mc.on('pinchstart', (e) => handler.startPinch(e));
mc.on('pinch', (e) => handler.handlePinch(e));
mc.on('pinchend', (e) => handler.endPinch(e));
```

**推荐指数：⭐⭐⭐⭐**

### 推荐方案 3：Panzoom（专注缩放平移）

**优势：**
- 专注于缩放和平移功能
- API 简单直观
- 支持触摸手势

**使用示例：**
```javascript
import Panzoom from '@panzoom/panzoom';

const panzoom = Panzoom(element, {
    maxScale: 5,
    minScale: 0.5,
    contain: 'outside',  // 限制在容器外
    cursor: 'grab'
});

// 绑定滚轮
element.parentElement.addEventListener('wheel', panzoom.zoomWithWheel);

// 程序化控制
panzoom.zoom(2);
panzoom.pan(100, 50);
panzoom.reset();
```

**推荐指数：⭐⭐⭐**

### 推荐方案 4：原生实现（零依赖）

**优势：**
- 零外部依赖
- 完全控制实现细节
- 最小化打包体积

**劣势：**
- 需要处理更多边缘情况
- 触摸事件处理复杂

**适用场景：**
- 对包体积有严格要求
- 需要深度定制交互行为

**推荐指数：⭐⭐⭐（可选）**

### 最终推荐组合

```
主方案：D3.js (d3-zoom + d3-selection)
  └─ 桌面端：D3 处理所有交互
  └─ 移动端：D3 + Hammer.js 增强触摸支持

备选方案：Panzoom
  └─ 快速实现，API 简单
```

## API 设计

### 高级 API（推荐使用）

```javascript
/**
 * 创建交互式等值线图
 */
function createInteractiveContour(container, config) {
    // container: Canvas 或 SVG 元素
    // config: 配置对象

    return {
        // ============================================
        // 方法
        // ============================================

        // 更新数据
        update(newData),

        // 设置视图范围
        setView(xMin, xMax, yMin, yMax),

        // 获取当前视图
        getView(),

        // 重置视图
        resetView(),

        // 缩放到指定区域
        zoomTo(x1, y1, x2, y2, options),

        // 平移到指定位置
        panTo(dx, dy, options),

        // 启用/禁用交互
        enableInteraction(enabled),

        // 销毁实例
        destroy(),

        // ============================================
        // 事件回调
        // ============================================

        // 视图变化
        onViewChange: (view) => {},

        // 悬停
        onHover: (point) => {},

        // 点击
        onClick: (point) => {},

        // 缩放开始/结束
        onZoomStart: () => {},
        onZoomEnd: () => {}
    };
}
```

### 使用示例

```javascript
// 基本用法
const chart = contourCore.createInteractiveContour('#canvas', {
    // 数据配置
    z: gridData,
    x: xCoords,
    y: yCoords,

    // 等值线配置
    contours: { type: 'fill' },
    colorscale: 'Viridis',

    // 交互配置
    interaction: {
        // 启用的功能
        zoom: true,
        pan: true,
        hover: true,

        // 缩放配置
        zoom: {
            wheel: true,
            box: true,
            scaleExtent: [0.5, 10],
            duration: 300  // 动画时长
        },

        // 平移配置
        pan: {
            drag: true,
            inertia: false  // 惯性效果
        },

        // 悬停配置
        hover: {
            tooltip: true,
            highlightLine: true,
            format: (point) => `x: ${point.x.toFixed(2)}, y: ${point.y.toFixed(2)}, z: ${point.z.toFixed(2)}`
        }
    }
});

// 监听事件
chart.onViewChange((view) => {
    console.log('当前视图范围:', view);
});

chart.onHover((point) => {
    console.log('悬停数据:', point);
});

// 程序化操作
chart.zoomTo(10, 20, 30, 40, { duration: 500 });

// 更新数据
chart.update({ z: newGridData });
```

## 性能优化策略

### 1. 渲染优化

```javascript
// 防抖：限制渲染频率
const debouncedRender = debounce(render, 16); // 60fps

// 节流：限制事件处理频率
const throttledHandler = throttle(handleMouseMove, 50);

// 增量更新：只重绘变化部分
function render(changes) {
    if (changes.view) {
        updateViewTransform();
    }
    if (changes.labels) {
        updateLabelPositions();
    }
}
```

### 2. 计算缓存

```javascript
// 缓存计算结果
const cache = {
    paths: null,
    labels: null,
    valid: false
};

function getContours() {
    if (!cache.valid) {
        cache.paths = computeContours();
        cache.labels = computeLabels();
        cache.valid = true;
    }
    return cache;
}

// 数据变化时使缓存失效
function invalidateCache() {
    cache.valid = false;
}
```

### 3. 虚拟化（大数据集）

```javascript
// 只渲染可见区域
function renderVisible() {
    const view = state.getView();
    const visiblePaths = filterVisiblePaths(allPaths, view);
    drawPaths(visiblePaths);
}
```

### 4. Web Worker（可选）

```javascript
// 将计算移到 Worker
const worker = new Worker('contour-worker.js');

worker.postMessage({ type: 'compute', data: grid });

worker.onmessage = (e) => {
    if (e.data.type === 'result') {
        drawContours(e.data.result);
    }
};
```
