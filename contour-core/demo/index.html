Contour-Core Demo 集合

高性能等值线生成库 - 纯 JavaScript 实现

核心特性

  • 零依赖，纯 JavaScript 实现
  • 支持 Node.js 和浏览器
  • 高性能处理（280+ 点/毫秒）
  • 完整 SSR 支持
  • 灵活的配置选项
  • 多种颜色方案

📚 使用建议

初学者：从「快速入门」开始，了解基本概念和 API 使用方法。
进阶用户：查看「自定义阈值」示例，学习如何精确控制等值线生成。
数据可视化：参考「热力图」示例，探索不同的可视化方式。
交互测试：使用「Canvas 交互测试」和「SVG 交互测试」体验完整的渲染功能和交互效果。

所有示例都包含完整的源代码，可以直接复制使用。如有问题，请参考项目文档或提交 Issue。
