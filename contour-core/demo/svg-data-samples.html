SVG 优势说明

矢量图形：无限缩放不失真，适合打印和高清显示
可交互：每条路径都是独立的 DOM 元素，可添加 CSS 样式和事件监听
文件体积小：纯文本格式，易于压缩和传输
SSR 友好：可以在服务端生成完整的 SVG 字符串
