自动 X/Y 坐标生成测试

功能说明：
现在 computeContours 和 render 函数支持直接传入 2D 数组（z 值），
系统会自动根据 z 数组的维度生成对应的 x 和 y 坐标数组：
  • x = [0, 1, 2, ..., n-1] （n 为列数）
  • y = [0, 1, 2, ..., m-1] （m 为行数）

显示坐标轴：只需设置 showAxes: true 即可自动显示 X/Y 轴
方式1: 直接传入 z 数组 + showAxes
方式2: 传入 {z, x, y} 对象 + showAxes
// 方式1: 直接传入 z 数组（新功能）+ 显示坐标轴 var z = [[2, 4, 7, 12, 13, 14, 15, 16], [3, 1, 6, 11, 12, 13, 16, 17], [4, 2, 7, 7, 11, 14, 17, 18], [5, 3, 8, 8, 13, 15, 18, 19], [7, 4, 10, 9, 16, 18, 20, 19], [9, 10, 5, 27, 23, 21, 21, 21], [11, 14, 17, 26, 25, 24, 23, 22]]; var result = contourCore.computeContours(z, { autocontour: true, ncontours: 10 }); // 系统自动生成: x = [0,1,2,3,4,5,6,7], y = [0,1,2,3,4,5,6] // 绘制时只需设置 showAxes: true 即可显示坐标轴 contourCore.renderers.canvas.drawContours(ctx, result, { width: 450, height: 400, coloring: 'fill', colorScale: mappedColors, showAxes: true, // ← 显示 X/Y 轴 axes: { // ← 可选：自定义轴配置 x: { title: 'X 轴', showgrid: true }, y: { title: 'Y 轴', showgrid: true } } }); // 方式2: 传入对象格式（原有方式） var grid = { z: z, x: [0, 1, 2, 3, 4, 5, 6, 7], y: [0, 1, 2, 3, 4, 5, 6] }; var result2 = contourCore.computeContours(grid, { autocontour: true, ncontours: 10 });
