分段颜色映射示例

使用 valueColorMap 参数实现分段颜色控制

分段颜色映射格式：[[值, 颜色], [值, 颜色], ...]
每个数组项定义一个边界值和对应的颜色。值在两个边界之间时使用较低边界的颜色。
例如：[[10, '#ff0000'], [20, '#00ff00'], [30, '#0000ff']] 表示：
• 值 < 10: 使用红色
• 10 ≤ 值 < 20: 使用绿色
• 20 ≤ 值 < 30: 使用蓝色
• 值 ≥ 30: 使用蓝色（最后一个颜色延续）

控制面板

格式: [[值, 颜色], [值, 颜色], ...]
0.5

当前参数

分段数量: -
等值线级别: -
数据范围: -

代码示例

// 使用分段颜色映射
var config = {
  z: gridData,
  valueColorMap: [
    [10, '#ff0000'],
    [20, '#00ff00'],
    [30, '#0000ff']
  ],
  contours: { type: 'fill' }
};

contourCore.render(canvas, config);
