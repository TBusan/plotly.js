Contour-Core 快速入门

纯 JavaScript 实现的高性能等值线生成库

核心特性

  • 零依赖 - 纯 JavaScript 实现，无需任何外部库
  • 跨平台 - 支持 Node.js 和浏览器环境
  • 高性能 - 每秒可处理 280+ 个数据点
  • SSR 就绪 - 完美支持服务端渲染
  • 灵活配置 - 支持自定义阈值、颜色映射和平滑算法

示例输出

使用示例

// 1. 引入库 const contourCore = require('./contour-core'); // 2. 准备数据 const grid = { z: [[10, 20, 30], [20, 30, 40], [30, 40, 50]], x: [0, 1, 2], y: [0, 1, 2] }; // 3. 计算等值线 const result = contourCore.computeContours(grid, { autocontour: true, ncontours: 10, smoothing: 0.3 }); // 4. 渲染到 Canvas const canvas = document.getElementById('canvas'); const ctx = canvas.getContext('2d'); contourCore.renderers.canvas.drawContours(ctx, result, { width: 600, height: 400, coloring: 'fill', colorscale: 'Viridis' });

API 参数说明

computeContours(grid, options)

grid: 输入数据对象
  • z: 二维数组，Z 值（必需）
  • x: X 坐标数组（可选）
  • y: Y 坐标数组（可选）

options: 配置选项
  • autocontour: 自动生成级别（默认: true）
  • ncontours: 级别数量（默认: 15）
  • thresholds: 自定义阈值数组
  • smoothing: 平滑系数（0-1，默认: 0）
