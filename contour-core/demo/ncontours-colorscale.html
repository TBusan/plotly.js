ncontours 与颜色映射示例

演示如何使用 ncontours 参数和自定义颜色方案

核心概念：
• ncontours：自动生成等值线时的目标数量，使用"优美刻度"算法生成美观的等值线级别
• colorscale：颜色映射方案，支持预设方案（如 Viridis、Hot）或自定义颜色数组
• reversescale：反转颜色方向

控制面板

10
自动生成的等值线数量
支持十六进制、rgb() 或颜色名称
0.5

当前参数

数据范围: -
等值线数量: -
等值线级别: -
颜色数量: -

代码示例

// 使用 ncontours 和 colorscale
var options = {
  autocontour: true,
  ncontours: 10,
  smoothing: 0.5
};

var result = contourCore.computeContours(grid, options);

// 构建颜色映射
var colorScale = buildColorScale(
  result.levels,
  'Viridis'
);
