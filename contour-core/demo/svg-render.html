使用方法

// 1. 引入库 const contourCore = require('./contour-core'); // 2. 计算等值线 const result = contourCore.computeContours(grid, { autocontour: true, ncontours: 15, smoothing: 0.5 }); // 3. 生成 SVG 字符串 const svgString = contourCore.renderers.svg.renderSVG(result, { width: 600, height: 400, coloring: 'fill', colorscale: 'Viridis', lineWidth: 1.5 }); // 4. 插入 DOM document.getElementById('container').innerHTML = svgString;

SVG 优势

矢量图形 - 无限缩放不失真，适合打印和高清显示
可交互 - 每条路径都是独立的 DOM 元素，可添加事件监听
可编辑 - 可以使用 CSS 样式控制外观
文件体积小 - 纯文本格式，易于压缩和传输
SSR 友好 - 可以在服务端生成完整的 SVG 字符串
